🤖 Robótica Industrial
Sala: 102
Integrantes: Lucas H, Bernardo, Richard, Kaio e Erique

📌 Descrição do Trabalho
Este trabalho consiste no desenvolvimento de um site institucional e informativo sobre robótica industrial, utilizando exclusivamente as tecnologias:

HTML5
CSS3
JavaScript (Vanilla)
🎯 Objetivo
O objetivo principal é apresentar, de forma clara, visual e interativa, os principais conceitos, soluções e tecnologias relacionados ao setor de automação industrial.

O site busca proporcionar uma experiência informativa e acessível, demonstrando como a robótica é aplicada na indústria e sua importância para a modernização dos processos produtivos.

🛠️ Tecnologias Utilizadas
Tecnologia	Utilização
HTML5	Estrutura e organização das páginas
CSS3	Estilização, layout e responsividade
JavaScript	Interatividade e funcionalidades dinâmicas
